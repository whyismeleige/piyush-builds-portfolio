# Piyush Builds Portfolio

A modern, minimalist portfolio website built with Next.js and TypeScript.

## Features

- Clean, responsive design
- MDX-powered blog
- Optimized performance
- Dark mode support
- Mobile-friendly

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Content**: MDX
- **Deployment**: Vercel
